# Fonts

Die Vorlage setzt mit pdflatex und nutzt XCharter (Fließtext) und Fira Sans (Überschriften)
aus TeX Live, beide offen lizenziert. Dieser Ordner ist für offen lizenzierte Font-Dateien
(OTF/TTF) samt Lizenz, falls später welche dazukommen. Das Dockerfile installiert alles aus
diesem Ordner; `rechnung doctor` listet sie. Systemfonts sind nie Default.
